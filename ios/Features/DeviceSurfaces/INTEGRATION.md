# DeviceSurfaces integration contract

This module implements the bounded B09 surface boundary. It does not claim completed E07/E08, a signed widget/share installation, real notification delivery, or human device acceptance. Speech/OCR, record retirement, dinner UI, app root and project generator remain with their assigned owners.

## Targets and resources

- App links `DeviceSurfaces` and includes `ios/Features/DeviceSurfaces/*.swift`, `DeviceSurfaces.xcstrings` and `AppShortcuts.xcstrings`.
- `RoomInTheCartWidget` uses `ios/Extensions/Widget`, suffix `.widget`, its Info.plist and the shared `DeviceSurfaces.xcstrings`; link only `DeviceSurfaces` and platform frameworks. The widget entry point is `@main RoomInTheCartWidget`; kind is `RoomInTheCartCapture`.
- `RoomInTheCartShare` uses `ios/Extensions/Share`, suffix `.share`, its Info.plist and the shared `DeviceSurfaces.xcstrings`; principal class `$(PRODUCT_MODULE_NAME).ShareViewController`. Link only `DeviceSurfaces` and platform frameworks.
- Both extensions require `APPLICATION_EXTENSION_API_ONLY=YES`. The package's SQLite system module is named `CDeviceSQLite` to avoid the existing LocalStore module name. Embedded extensions require the root-owned target/product/signing setup.
- Plist keys: `RITCWidgetAppGroup = $(RITC_WIDGET_APP_GROUP)`, `RITCShareInboxAppGroup = $(RITC_SHARE_INBOX_APP_GROUP)`, `RITCSurfaceURLScheme = $(RITC_SURFACE_URL_SCHEME)`. Widget sees only its group + scheme; Share sees only its inbox group. App needs all three and URL registration. No actual App Group is fabricated or registered by these files. Missing, unexpanded or invalid values fail closed.
- Keep the groups separate, and validate the app's three values together with `SurfaceConfiguration`. Never put the private SQLite store, tokens or recovery files in either group. Root owns narrow entitlements and Data Protection capability. The inbox creates a protected `DeviceSurfaces/selected-text.sqlite`; widget reads only `DeviceSurfaces/widget-projection-v1.json`.

## App root ports

1. **Inbox review:** after an unlocked private adult authorization, create `SelectedTextReviewModel(inbox:authorizedGeneration:review:)`. The generation callback must return nil for contributor/helper/locked/revoked state. Tear down or call `invalidateScope()` immediately on any persona change; do not list raw unassigned incoming text in a contributor session. The review closure is an explicitly presented, cancellable list-import review. Return nil on Cancel. Return `CommittedSelectedTextImport(operationID:digest:)` only after a durable ledger commit or reopening that operation's durable receipt. The model then acknowledges the inbox and deletes redundant raw staging text.
2. **Stable import bridge:** `ShoppingLedger.stageImport(text:source:importID:)` now accepts the inbox operation UUID. The app-owned `LedgerSelectedTextPort` and `SurfaceImportBridge` persist the complete preview and decisions in a protected private journal before the actual LedgerModel transaction. They verify the saved `importBatches` receipt plus inbox digest before acknowledgment. Explicit stale-review recovery reloads the ledger and preserves bounded prior confirmed attempts under the same UUID. See [app integration](APP-INTEGRATION.md). A crash after commit cannot silently restage a random identity or add a second list.
3. **Widget publication:** after a successful authorized app commit, issue a random `RouteHandle`, store its `PrivateRoute` mapping in the private persona store, then `WidgetProjectionFile.publishAfterCommit`. Only generic enum/handle/time/generation are shared. Call `WidgetCenter.shared.reloadTimelines(ofKind: "RoomInTheCartCapture")`. On sign-out/scope changes/source erasure, revoke mappings, `clear(now:)` and reload. A stale widget displays only generic text.
4. **Deep link/shortcut:** `.onOpenURL` first uses `SurfaceURLCodec.parse`; a URL is only a locator. Resolve handles with `SurfaceRouter.resolve` against the current app-built `RouteAuthorization`, never data decoded from a group/URL. No handle means generic capture. Observe `SurfaceCaptureRequests.shared.pending` for app-only AppIntent requests; take a pending request once and resolve it against the current persona when the app is ready. Contributor entry is own-request review; helper/private adult access is never inferred from a shortcut.
5. **Reminders:** instantiate `ReminderStore` at a private per-persona app URL, `IOSNotificationScheduler`, and `ReminderCoordinator`. Present `ReminderEditorView` from a specific S07 offer or S12 deferral. Supply a stable reminder/target identity, current source revision, real expiry, offer cutoff when applicable, and the private route handle. `currentAuthorization` returns a generation only while both persona AND target revision remain authorized. A chosen dinner without a date cannot be given an invented reminder date.
6. **Lifecycle:** use coordinator `cancel`, `cancelAll(personaID:)`, and `reconcileAll()` on explicit off, current target edits, handled/deleted deferrals, revocation and foreground/restart. A new source revision needs a new user review. Keep private desired records until notification cancellation reconciles; the record-retirement owner decides final private metadata erasure. No background timing/revocation guarantee is asserted while the app is offline.
7. **Notification tap:** retain `SurfaceNotificationDelegate` in the root and assign/multiplex it through `UNUserNotificationCenter.delegate` (weak). Its callback contains only a validated `RouteHandle`. Authenticate/reload the current target, then use `ReminderOpening.evaluate` and the app's authoritative current cutoff; a delayed offer opens Await pickup and never manufactures fill. Do not use a notification's old source revision as authorization. Expired locator/grant goes to a generic unavailable route. The delegate suppresses duplicate foreground announcements.

## Implemented bounds and failure semantics

Selected text is limited to 64 KiB combined original+edited UTF-8, 500 lines, 20 pending entries, 1 MiB pending payload and 10,000 deduplication receipts. It expires after seven days. Identical operation/body returns its original receipt; changed-body replay rejects. Distinct intentional shares stay distinct. Consumed/discarded/expired entries retain only digest/identity/time/status tombstones so late replay cannot recreate text. SQLite uses transactions, busy timeout, complete iOS file protection, secure deletion and a 2 MiB SQLite value limit. Cancellation before Save writes no entry. Success acknowledges staging only. Host item-provider loading is OS-managed; the returned selected text is checked before storage and no unbounded attachment type is accepted.

Reminder store limits are 32 active reminders and 2,048 total local records; excess fails closed instead of presenting a false scheduled badge. Desired state precedes OS registration. OS operations are serialized and version-checked, so cancellation/new edits defeat late callbacks. Permission is requested only by explicit Schedule. Unknown/denied/failing registration remains visibly unscheduled/retryable. Quiet hours reject the chosen instant without shifting it; DST gaps reject and ambiguous civil times need a confirmed offset. The OS adapter uses the reviewed instant's fixed GMT offset in its nonrepeating calendar trigger, retaining the original IANA zone privately, and verifies the next trigger date matches. The notification has only the brand, generic English/Spanish body and opaque handle—no food, money, names, counts or private notes.
