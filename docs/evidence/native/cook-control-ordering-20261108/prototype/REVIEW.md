R2 is frozen for root execution. R1 remains unchanged. This package contains a pure mailbox/admission reducer and MainActor coordinator, with12 deterministic manually driven tests; it does not invoke native speech. No Swift/compiler/test execution has been performed by the preparing agent.

Fixed two reviewed defects: repeated audio-preparation completion could enqueue duplicate Start/Resume or release the still-active lease; mailbox sequence fields did not reject duplicate/older commands. R2 claims each preparation result once, preserves its active lease on duplicate delivery, and rejects duplicate/older admission and revocation commands. Three regression tests were added.

Known scope gaps before a production adapter: no natural end/cancel routing, owner-thread implementation or automatic close/deinit teardown. A preparation completion after coordinator deallocation currently returns without releasing through that coordinator, so a production transport must own its lease teardown independently; r2 is not sufficient for a production lifetime. Repeat while speaking currently returns false instead of queuing the explicit request behind Stop; that is required integration work. The fake does not model real AVAudioSession lease ownership or a physically blocked thread. It models delayed native results only. Completion envelopes still contain the command/text; production result events should carry operation identity only. No acoustic/privacy, real responsiveness or SDK ownership result follows from these tests.
