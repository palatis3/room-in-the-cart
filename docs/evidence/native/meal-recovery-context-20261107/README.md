# Recovery context history

Reviewed pure-domain prerequisite for post-arrival whole-meal replacement. New outside demands, calendar moves and explicit confirmation of an unknown deadline append revisioned context events; they do not rewrite the original meals or earlier recovery events. A context change invalidates an older replacement review. Calendar movement retains the saved deadline. Exact replay remains idempotent. Legacy state without contextChanges still decodes.
