# Frozen theme candidate source review

No concrete product regression was found in this three-file diff. No corrective product patch is justified by this review or the run4 idle evidence. The three parent/candidate hashes and consolidated patch hash match the frozen manifest; static comparisons are recorded separately. This is a bounded source finding, not a runtime or full-design acceptance claim.

- **Focus and input:** both helper overloads return native `TextField<Text>`, preserve the supplied Binding and vertical axis, and only add an explicit prompt Text. All existing `.focused` arguments and accessibility identifiers are byte-identical. The enclosing FocusState, draft initialization, identity-resolved collection binding, keyboard Done focus-nil closure, review focus reset and presentation modifiers remain unchanged. No timer, responder override, new state, explicit animation or asynchronous input operation is introduced. The existing authorization TimelineView remains outside the form and unchanged; this does not establish any relationship to the idle stall.
- **Labels:** all 14 fields now have persistent purposes, using the same `dinnerText` localization result as their existing title. This helper receives an already localized String and does not add a second localization table/key or alter user text. Existing Notes/ingredient-exclusions labels remain single modifiers. Repeated ingredient/group fields retain their native value and original collection identity; no new element merging or identity assignment is introduced. Source cannot establish spoken VoiceOver order or all-language layout.
- **Actions and disabled state:** the four mutually exclusive primary branches use the existing PrimaryAction without changing their closures, enabled expressions or identifiers. PrimaryAction still reads `isEnabled` and reduces opacity; `.disabled` still applies to the Button. Secondary styling retains existing disabled limits and handlers. Destructive controls retain `.destructive` and `.borderless`; only their foreground changes to the existing error asset. No action is moved into a gesture or expanded to a parent row handler. Permission checks, validation, model writes and completion/dismiss logic are unchanged.
- **WorkingForm:** the content remains native Form content, with Sections and ForEach identities retained. Group adds row-background preference without a wrapping stack, nested scroll container or geometry reader. The content is rebuilt when its containing view is evaluated and stores no independent mutable state. The existing workingSurface applies canvas/ink; row treatment is applied inside Form. This source structure and retained renders support the intended palette, but do not prove all list diffing/focus timing behavior identical to the original type tree. The root's run4 Dark stall remains unresolved; source inspection cannot assign or exclude framework timing causality.
- **Supply and errors:** DinnerIdeaSupplyViews changes only the embedded borderless supply-review button foreground. The entire private IdeaSupplyEditor, evidence bindings, revision/workspace guards and sheet save/cancel behavior remain byte-identical. The independent IdeaSupplyTheme proposal is excluded. DinnerFeedback still uses its existing `.red` error text and existing accessibility focus; this is a pre-existing design gap, not a regression introduced by this patch. No claim that every Dinner error or native Form now meets the semantic-color contract is made.

Root-reported successful Light visual-v4 and earlier partial Dark paths are separate execution evidence, not a source proof of universal behavior. The run5 instrumented attempt remains a diagnostic and cannot itself establish repair.
